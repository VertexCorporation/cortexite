인공지능의 코어

수백 개의 인공지능 모델을 하나의 플랫폼에 통합한 Cortex는 온라인, 오프라인 환경에서 데이터를 전혀 저장하지 않고 작동합니다.

강력함, 프라이버시, 무제한

Cortex는 모든 요청에 가장 적합한 모델을 선택하며, 프라이버시를 타협하지 않습니다.

01

오프라인 AI

인터넷 연결 없이 기기의 성능만으로 작동하는 모델을 통해 어디서나 100% 프라이버시를 보장받으며 대화하세요.

02

제로 데이터 정책

대화 내용을 절대 저장하지 않습니다. 오픈소스 구조를 통해 소스 코드를 누구나 검토할 수 있습니다.

03

다이내믹 채팅 엔진

수백 개의 모델 중 최적의 모델을 자동으로 선택하며, 날씨, 코드 실행, 실시간 시장 데이터 기능을 갖추고 있습니다.

2030년, 인공지능의 중심지.

Cortex는 전 세계 사용자를 위한 인공지능의 중심지가 되어 수백 개의 모델을 수백만 명의 사용자에게 제공하는 것을 목표로 합니다.

우리는 지속적인 혁신, 오프라인 AI 기능의 확장, 그리고 사용자가 직접 모델을 훈련하고 공유할 수 있는 개방형 생태계 구축에 전념하고 있습니다.
